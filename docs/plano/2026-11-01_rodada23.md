# Plano — rodada 23: cálculo e EAP no build

Pergunta (`docs/plano/2026-10-31_rodada21.md` §2): o cálculo das gavetas reproduz o atual e entrega a EAP lastreada
no HTML? Método: o mesmo da rodada 22 (`CLAUDE.md`). O Opus gerencia, Sonnet e Haiku executam em worktrees, há
`vcm balanco` e o Fable faz o aceite no PR.

Regras do mantenedor que pesam aqui (`CLAUDE.md`): Python calcula; o HTML e o JS só apresentam o que o Python
calculou e formatou. A formatação é brasileira (`1.234,56`) e as unidades são SI.

## Critério da rodada (fixado antes)

1. **Caminho de volta completo:** todo nó da EAP no HTML abre os serviços, todo serviço abre os fatos usados e todo
   fato abre a evidência (documento, onde, trecho, executor). Nenhum número aparece no HTML sem esse caminho.
2. **Nenhum cálculo em JS:** o template só lê `dados.eap`. Os valores chegam formatados do Python.
3. **Recálculo incremental:** mudar um fato recalcula só os serviços que dependem dele. Os outros são reaproveitados
   com o mesmo valor.
4. **Paridade mantida:** `paridade.json` continua vazio nos testes.
